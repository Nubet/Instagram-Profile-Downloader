# InstaBulk Profile Downloader

A powerful and user-friendly browser extension for downloading Instagram profile content in bulk.

## Features

- **Bulk Download:** Fetch all posts from any public Instagram profile with a single click.
- **Selective Download:** Choose specific posts manually or define a range of posts to download.
- **Smart Scraping:** Built-in delays and cooldowns (customizable in settings) to ensure safe and stable downloading without getting rate-limited.
- **Media & Captions:** Automatically saves the post images along with their captions in an organized folder structure.

## How to use

1. Install the extension in your browser.
2. Navigate to any public Instagram profile.
3. Click on the InstaBulk extension icon in your toolbar.
4. Click **Fetch all posts** to start gathering the posts.
5. Once fetched, choose which posts you want to download and hit the **Download** button.

## Settings

You can customize the extension's behavior by clicking the gear icon ⚙️ in the popup:
- **Cooldown batch size & delays:** Adjust the speed at which the extension scrolls and gathers posts to balance speed with stability.
